# SVineetha — Portfolio

A responsive React + TypeScript portfolio starter for a Senior Content Engineer, built with Vite and ready to publish with GitHub Pages.

## Get started

1. Install Node.js (LTS) if it is not already installed.
2. In this folder, install dependencies with `npm install`.
3. Start the local preview with `npm run dev` and open the URL Vite prints.
4. Run `npm run build` to verify the production build; the output is generated in `dist/`.

## Make it yours

Update `src/App.tsx` before publishing:

- Replace `[Your name]` and the About copy with your own name and bio.
- Replace the three sample project prompts with real work, your contribution, and outcomes. Do not include confidential information.
- Replace `your.email@example.com` with your preferred public contact email.
- Adjust the skills to match your experience.
- The GitHub links already point to `https://github.com/SVineetha`.

Edit `src/styles.css` to adjust colors, typography, or layout. Google Fonts are loaded from the web; system serif and sans-serif fallbacks are included.

## Publish on GitHub Pages

1. Create a repository named **SVineetha.github.io** under the **SVineetha** account. This exact repository name gives you the user-site URL `https://svineetha.github.io/`.
2. Push this project to that repository. If you already have a local repository, set the GitHub repository as its remote and push the default branch (usually `main`).
3. In GitHub, open **Settings → Pages** and set the build source to **GitHub Actions**.
4. This project uses relative asset paths, so it can also be published from a differently named project repository, normally at `https://svineetha.github.io/<repository-name>/`.

A workflow can build `dist/` and deploy it to GitHub Pages automatically after each push to `main`. GitHub Pages serves static files only; do not commit secrets or private data into this public repository.
